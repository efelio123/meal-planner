# Recipes visual references

These twelve dark-theme PNGs were rendered from the seven approved interactive
recipe mockups and visually inspected on October 5, 2026. Use them for
side-by-side comparison with the running app; do not implement from filenames
or plan prose alone. The approved behavior and scope are in
`docs/plans/household-scoped-recipes.md`.

| View | PNGs |
| --- | --- |
| Recipes library | `recipes-library-grid.png`, `recipes-library-list.png` |
| Recipe detail | `recipe-detail.png` |
| Full recipe editor | `recipe-editor.png`, `recipe-editor-more-details.png` |
| Ingredient search, details, inline Food item creation | `ingredient-search.png`, `ingredient-details.png`, `ingredient-create-food.png` |
| Cover choices and emoji entry | `cover-choice-initials-emoji.png`, `cover-emoji-entry.png` |
| Direction-step editing section | `directions-editor-section.png` |
| Household archived recipes | `archived-recipes.png` |

The direction-step image magnifies a section of the full Create/Edit Recipe
form; it does not authorize a separate directions-only page. The cover PNGs
omit the source mockup's now-deferred photo choice. Native status bars, emoji
artwork, and system navigation may vary by platform; report any other visual
deviation rather than silently accepting it.
