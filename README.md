# Meal Planner

A household-first meal-planning application that helps families turn recipes and ingredients on hand into a shared shopping list.

## The problem

Planning meals usually means juggling saved recipes, a calendar, pantry items, texts between family members, and a separate grocery list.

Meal Planner is being built to simplify that weekly workflow:

1. Save family recipes.
2. Plan meals for the week.
3. Note what ingredients are already available.
4. Calculate only the missing quantities.
5. Shop from one shared list.

## Planned features

- Shared household shopping lists
- Recipe library and recipe creation
- Food catalog with normalized ingredient names and units
- Weekly meal-planning calendar
- Quantity-aware “ingredients on hand” workflow
- Automatic shopping-list generation for missing ingredients
- Household invitations and collaboration
- Native iOS and Android applications

## Planned architecture

- React Native, Expo, and TypeScript mobile application
- Python and FastAPI API
- PostgreSQL database
- Managed cloud deployment for staging and production
- GitHub Actions for automated testing and deployment

## Status

Early development / pre-alpha.

The project began as a working private home-server dashboard and is being rebuilt as a secure, multi-household consumer application.

## Development goals

This project is also a hands-on exploration of:

- Mobile application development
- API and database design
- Authentication and authorization
- Multitenant systems
- Cloud deployment and operations
- Automated testing and CI/CD
